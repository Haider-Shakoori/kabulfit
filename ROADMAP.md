# KabulFit Production Roadmap

Work is delivered in reviewable production-sized batches. Every batch must update `PROJECT_STATUS.md`, run relevant tests, pass formatting/build/security checks and remain unmerged until CI is green.

The Laravel application is the shared commerce platform for both the web storefront and the Flutter mobile app. From Batch 3 onward, domain work must expose stable, versioned API contracts where the mobile app will need the same business capability. Pricing, inventory, measurements, orders, payments, Stripe webhooks, roles and audit history remain server-authoritative; the mobile app must not duplicate business rules.

1. ✅ **Foundation, localization and SEO primitives** — Laravel 12 scaffold, `en/fa/ps`, RTL, design tokens, catalog foundation, robots/sitemap, legacy redirect architecture, tests and CI. Merged via PR #1.
2. ✅ **Reference visual-fidelity system** — live-site visual/content inventory, reusable components/tokens, responsive header/footer/homepage, media strategy and accessibility pass. Merged via PR #2.
3. ✅ **Catalog domain + mobile catalog API** — categories/collections, media, variants, sizes/colors, inventory, search/filter/sort, related/recently viewed products, complete Product/Offer/Breadcrumb/ItemList schema, plus versioned read APIs for the Flutter catalog.
4. ✅ **Authentication, customer account + mobile API authentication** — registration/login/reset/verification, addresses, account authorization, noindex/throttling, secure API tokens/sessions, device-aware authentication and account endpoints for mobile.
5. ✅ **Cart, wishlist, checkout + Stripe platform payments** — durable server-authoritative cart, decimal-safe totals, coupons, shipping calculation, checkout state machine, Stripe PaymentIntent/payment architecture, verified webhooks, idempotency, failed/cancelled/succeeded states, refunds where permitted, and shared web/mobile checkout APIs.
6. ✅ **Measurements and custom tailoring + mobile measurement API** — configurable measurement definitions, cm/inch conversion, reusable profiles, customer tailoring history/detail, immutable order-time snapshots, validation, visual guides, tailoring CTA integration and mobile-safe measurement/profile/tailoring endpoints.
7. ✅ **Orders, shipping, notifications + mobile event contract** — transactional order lifecycle, immutable status history, shipping configuration/tracking, queueable localized order/shipment notifications, web/mobile order history/detail/tracking and UUID-cursor event hooks suitable for future push notifications.
8. ✅ **Admin, roles, Stripe operations and audit logging** — custom admin dashboard, catalog/content/order/customer/measurement/tailoring management, first-party roles/permissions/policies, settings/SEO, Stripe payment visibility/full refunds, webhook/payment audit trail, immutable admin audit logs and authorization tests.
9. 🟡 **Tailor dashboard** — scoped assignments, garment/measurement views, append-only notes/events, controlled statuses/reassignment, strict authorization and authorized staff APIs for future mobile clients. Implementation complete with green feature-branch CI; PR CI/merge pending.
10. **Content/SEO CMS and legacy migration** — pages/blog, localized editorial metadata/schema/internal linking, sitemap indexes, full old-URL inventory and verified 301 mappings.
11. **Performance/media/API hardening** — AVIF/WebP responsive pipeline, caching/query tuning, CDN readiness, asset budgets, N+1 review, queue/scheduler deployment hardening, API pagination/rate limits/conditional caching and mobile payload optimization.
12. **Flutter mobile foundation** — separate KabulFit mobile application repository, production flavor/environment strategy, API client, secure storage, routing/state architecture, `en/fa/ps` localization with RTL, shared brand design system, authentication shell, error handling, analytics/consent hooks, CI and Android/iOS build foundations.
13. **Flutter shopping experience** — mobile home, categories, collections, search/filter/sort, product detail, variants, stock state, wishlist, cart, account/address flows, image caching and deep-link-ready product/category routing.
14. **Flutter tailoring, Stripe checkout, orders and notifications** — saved/new measurements, measurement guide, tailor-this-outfit flow, shipping/checkout, Stripe mobile payment sheet or equivalent official SDK flow, webhook-confirmed order creation, order history/detail/tracking, push-notification integration and relevant deep links.
15. **Cross-platform E2E, accessibility, responsive and performance QA** — browser tests for critical web journeys, Flutter integration tests for critical mobile journeys, WCAG 2.2 AA web review, mobile accessibility checks, required web viewport regression from 320px through 1920px, API contract tests, Stripe test-mode flows and performance budgets.
16. **Production readiness + web/mobile releases** — fresh installs, complete automated test suites, dependency/security audits, Lighthouse/Core Web Vitals evidence, API/mobile performance evidence, deployment/runbooks/backups/logging/error handling, Stripe production checklist, Android/iOS signing/release configuration, Play Store/App Store readiness and final acceptance report.
